# Contributing to env-ok

Thanks for helping improve **env-ok**.

## Development

```bash
git clone https://github.com/theinfyark/env-ok.git
cd env-ok
npm install
npm test
npm run build
```

## Guidelines

- Keep the public API small, predictable, and well typed
- Prefer zero dependencies
- Add tests for bug fixes and new features
- Update `CHANGELOG.md` for user-facing changes
- Use clear commit messages (no Cursor co-author trailers)
